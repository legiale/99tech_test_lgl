## Application scope

- Role: Backend Engineer.
- Selected problems: 4, 5, and 6, as confirmed by the candidate.
- Language/framework: TypeScript for problems 4 and 5; ExpressJS and SQLite for problem 5. Problem 6 specifies a proposed TypeScript/Express module with PostgreSQL, Redis, and SSE; implementation is outside that problem's deliverable.
- Problem statements: [problem 4](src/problem4/README.md), [problem 5](src/problem5/README.md), and [problem 6](src/problem6/README.md) supplied by the candidate. The linked Notion page could not be accessed during setup.

## Requirements supplied by the candidate

1. Submit the application together with attached or linked solutions.
2. Start with the skeletal template in the official GitHub repository.
3. Attempt every problem required for the selected role, even if a solution is incomplete.
4. Record uncertainties and explicitly declare assumptions in each solution.
5. Use creativity where constraints are unclear; the challenge allows ChatGPT use.
6. Make the submission easy to view. A browsable repository link is acceptable; requiring reviewers to unzip files is discouraged.
7. Select the appropriate role tab in the problems page. The assigned problem set depends on the role.

The supplied overview recommends applicants interested in trying full-stack work apply for Frontend or Backend and ask about opportunities to work in the other area.

## Template adaptation

Each selected problem includes the template's empty `.keep` convention plus a local README and test directory.
